# Rain Window

늦은 밤 카페 안에서 비 오는 도시를 바라보는 한 장면의 웹 감상 프로젝트입니다. 접속하면 중간 강도의 비가 움직이며, 소리는 사용자가 직접 켜기 전까지 재생되지 않습니다.

## 실행과 검사

Node.js 22.12 이상과 npm을 사용합니다. 이 작업에서는 Node.js 25.9.0으로 검증했습니다.

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

브라우저 검사는 Playwright Chromium이 필요합니다. 먼저 `npx playwright install chromium`으로 설치하고 실행 중인 서버 URL을 `QA_BASE_URL`에 지정합니다. 기본값은 `http://127.0.0.1:5174`입니다.

```powershell
$env:QA_BASE_URL='http://127.0.0.1:43911'
npm run test:e2e
```

## 동작

- 비 강도는 물방울 수와 흐르는 속도, 빗소리의 질감·크기를 조절합니다. 0에서는 새로 흐르는 비가 멈추고 유리에 남은 방울은 유지됩니다.
- 일시정지는 영상과 소리를 함께 멈추며 재개 시 기존 음량과 소리 선택을 유지합니다. 음량을 올리는 것만으로 소리가 켜지지는 않습니다.
- 비활성 탭에서는 렌더링과 소리를 중단합니다. 탭 복귀 후 브라우저가 소리 재개를 거부하면 버튼으로 다시 시도할 수 있습니다.
- 모션 감소 설정에서는 정지 장면으로 시작합니다. 명시적으로 재생할 수 있으며, 실행 중 모션 감소를 켜면 즉시 정지합니다.
- 전체 화면은 지원되는 경우에만 제공하며 실패해도 감상은 계속됩니다.
- Canvas 실패 시 CSS로 만든 정적 야경을 표시합니다. 오디오 실패는 그래픽을 중단하지 않습니다.

## 구현과 자산 출처

Vite + TypeScript, Canvas 2D, Web Audio API만 사용합니다. 런타임 외부 라이브러리·이미지·음원·웹 폰트·API는 없습니다. 로그인, DB, 위치 권한과 사용자 정보 수집 코드를 사용하지 않습니다.

| 자산                     | 출처·방식                                                       |
| ------------------------ | --------------------------------------------------------------- |
| 도시·젖은 도로·불빛      | `src/scene.ts`의 직접 작성한 절차적 Canvas 그래픽               |
| 물방울·물길              | `src/rain.ts`의 타원 마스크·배경 부분 확대·하이라이트           |
| 정적 대체 장면·실내 반사 | `src/style.css`의 직접 작성한 CSS 그래픽                        |
| 빗소리                   | `src/audio.ts`의 스테레오 노이즈·저역 필터 합성, 단일 반복 소스 |
| 아이콘·favicon           | 직접 작성한 SVG 경로, 일부 시스템 문자                          |
| 글꼴                     | 기기에 설치된 Arial, Malgun Gothic, Georgia 및 시스템 대체 글꼴 |

직접 생성한 자산에 제3자 이미지·음원 재배포 라이선스는 필요하지 않습니다. 개발 도구의 라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기록했습니다.

배경은 초기화·크기 변경 시에만 렌더링합니다. 모바일(가로 640px 이하)에서는 DPR 1.5, 100만 픽셀, 140개 방울, 30fps로 제한합니다. 그 외에는 DPR 2, 210만 픽셀, 320개 방울, 60fps가 상한입니다. 프레임 간격은 최대 50ms이며 정지 후 시간 누적을 버립니다. 이 수치는 상한이며 모든 기기에서 목표 fps를 보장하지 않습니다.

## 배포

`npm run build`로 생성되는 `dist/`가 완전한 정적 배포 산출물입니다. 루트 경로에 서비스하는 정적 호스팅에 배포할 수 있습니다. Sites 설정은 `.openai/hosting.json`에 있으며 서버 런타임·데이터 바인딩은 없습니다. 자격 증명은 프로젝트에 저장하지 않습니다.

Sites 배포는 검증된 소스 커밋을 지정된 저장소에 push한 후, 동일 소스의 `dist/`와 호스팅 설정만 패키징하고 버전을 저장·공개 배포하는 순서입니다. 캐시된 이전 번들을 피하기 위해 배포 후 HTML과 해시된 자산, 비로그인 접근을 확인합니다.

## 검증과 한계

핵심 상태·프레임 예산·오디오 중복 방지 단위 검사와 Chromium 브라우저 검사를 제공합니다. 실제 캡처는 [데스크톱](docs/screenshots/desktop.png), [모바일](docs/screenshots/mobile.png)입니다. 모바일은 브라우저 뷰포트 에뮬레이션이며 실제 휴대전화와 Safari·Firefox 검증을 대신하지 않습니다.

물방울은 근사 렌즈 효과이며 실제 굴절·충돌·합쳐짐·유체 시뮬레이션은 없습니다. 빗소리는 현장 녹음이 아닌 8초 길이의 합성 노이즈 루프입니다. 장면·설정은 저장하지 않으며 새로 접속하면 기본값으로 돌아옵니다. 전체 화면과 오디오는 브라우저·운영체제 정책의 영향을 받습니다.

기술 참고: [MDN Canvas 최적화](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas), [Web Audio 권장 사항](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices).
