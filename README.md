# Rain Window

**늦은 밤, 비 오는 도시를 바라보는 작은 창가.**

고층 창가에서 내려다보는 실제 도쿄 야경과 따뜻한 불빛, 유리에 부딪혀 맺히고 흘러내리는 빗물을 감상하는 웹 프로젝트입니다. 접속하면 비가 움직이고, 원할 때 빗소리를 켤 수 있습니다. 기본은 무음입니다.

**[Rain Window 감상하기 →](https://rain-window.okorion.chatgpt.site)**

[![Rain Window 데스크톱 실제 화면 — 흐릿한 도시 야경과 유리 위 물방울](docs/screenshots/desktop.png)](https://rain-window.okorion.chatgpt.site)

## 감상과 조작

- **비의 세기** — 창밖 비·빗안개와 유리의 방울 수·흐르는 속도, 빗소리의 질감·크기를 조절합니다. 0에서는 창밖 비가 사라지고 유리에 남은 방울은 유지됩니다.
- **바람** — 왼쪽 100%부터 무풍, 오른쪽 100%까지 조절합니다. 창밖 비의 기울기·이동, 흐르는 빗물·미세 튀김과 구름 이동에 반영됩니다. 기본은 오른쪽 20%입니다.
- **일시정지·재생** — 움직임과 소리를 함께 멈추고, 이전 음향 설정으로 재개합니다.
- **빗소리·음량** — 소리는 직접 켜야 재생됩니다. 음량 조절만으로 소리가 켜지지 않습니다.
- **전체 화면** — 지원되는 브라우저에서 화면을 가득 채워 감상할 수 있습니다.
- **배경음악** — 하단 ♫ 버튼으로 **Rain · oh**를 켭니다. 74 BPM의 전자피아노·베이스·절제된 드럼으로 구성한 약 1분 44초 로파이 곡입니다. 기본은 꺼짐이며, 빗소리와 별도로 음량을 조절합니다. 일시정지·숨김 탭에서는 멈추고 복귀 시 기존 위치에서 이어집니다.
- **시계** — 오른쪽 위에 기기 현지 시각을 24시간제로 표시합니다. 감상을 정지해도 시계는 갱신됩니다.

모바일에서도 같은 컨트롤을 사용할 수 있습니다.

구름이 천천히 지나가고, 사진 속 도로 경로를 따라 차량 불빛이 움직이며, 일부 창문이 서서히 켜지고 꺼집니다. 가로등과 생활 조명, 젖은 도로의 작은 반사는 새벽에도 유지됩니다. 비를 0으로 줄여도 도시는 움직입니다. 일시정지는 구름·차량·조명 변화까지 함께 멈춥니다.

차량은 **도로 길이 약 1.2km, 양방향 시속 18·21km**를 가정해 이동합니다. `이동 거리 = 속도 ÷ 3.6 × 경과 초`로 계산하고, 지면의 거리를 원근 투영하므로 먼 차량일수록 화면 이동량이 작습니다. 도로 전체 통과에는 약 3.4~4분이 걸립니다. 같은 방향 차량은 같은 속도로 간격을 유지합니다. 사진의 실제 축척·카메라 정보가 없어 설정한 장면용 근사이며, 실측 교통 속도나 정밀한 지도 기반 시뮬레이션은 아닙니다.

교통량도 기기 현지 시간에 따라 달라집니다. 전체 도로 경로 기준 새벽 02–05시 약 8대, 출근 08–09시·퇴근 18–19시 약 40대, 낮 10–16시 약 26대, 22시 약 20대이며 사이 시간에는 서서히 전환합니다. 화면 잘림·원거리·빗물 가림으로 실제 보이는 대수는 더 적을 수 있습니다. 실시간 교통 정보가 아닌 시간대별 연출입니다. 차량 불빛은 사진 노출에 맞춰 보강했으며 속도는 유지합니다.

빌딩 조명은 **사용자 기기의 현지 시간**을 따릅니다. 낮에도 배경은 일반적인 야경을 유지하며 위치 권한이나 외부 시간 API를 사용하지 않습니다.

| 현지 시간 | 사무실 조명 |
| --- | --- |
| 08–22시 | 일반 야경, 충분한 창문 불빛 |
| 22–01시 | 점진적으로 소등 |
| 01–05시 | 소등, 도로·차량·붉은 안전등은 유지 |
| 05–08시 | 점진적으로 다시 점등 |

정지·비활성 탭에서 복귀하면 현재 시간을 다시 적용합니다.

## 로컬 실행

Node.js 22.12 이상과 npm이 필요합니다. 검증에 사용한 환경은 Node.js 25.9.0입니다.

```sh
git clone https://github.com/okorion/rain-window.git
cd rain-window
npm ci
npm run dev
```

터미널에 표시된 로컬 주소로 접속하세요.

```sh
# 정적 배포 파일 생성
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 구현 방식

**Vite · TypeScript · WebGL · Canvas 2D · Web Audio API**

배경은 흐린 도시 사진으로, 물방울 안의 반사는 선명한 사진으로 각각 캐시합니다. WebGL 셰이더가 방울의 곡면을 계산해 주변 도시를 뒤집고 휘어 비추며, 빛과 색은 같은 도시 사진에서 가져옵니다. 방울마다 일정한 흰 테두리를 그리지 않습니다.

도시와 유리 사이에는 세 깊이의 비가 내립니다. 가로등·생활 조명·차량 불빛 주변에서만 짧은 빗줄기와 빗안개가 드러나며, 어두운 하늘에는 균일한 선을 그리지 않습니다. 빛에서 멀어질수록 부드럽게 사라지고 따뜻한 조명과 차가운 조명의 색을 따릅니다. 물방울 내부의 굴절 장면에도 동일하게 반영되며, 사진 실패 시 기본 야경의 조명 주변에서도 동작합니다.

빗물은 불규칙한 간격으로 유리에 닿아 약 45ms 동안 퍼진 뒤, 약 0.48초 이내에 수축해 방울로 남습니다. 주변에는 작은 물방울 2~4개가 짧게 튀며, 수면처럼 큰 동심원은 만들지 않습니다. 충격 횟수는 비 강도와 화면 면적에 비례하며 비 0·일시정지·비활성 탭에서는 멈춥니다.

큰 방울은 유리에 잠시 붙어 있다가 가속하고, 속도에 따라 길어집니다. 지나간 자리는 짧게 남는 얇은 물막과 작은 방울로 표현하며, 경로의 작은 방울을 흡수하는 제한적인 근사 동작을 적용합니다. 새 충격은 기존 정지 방울 공간을 재사용해 전체 개수를 제한합니다. 모든 방울과 잔여 물막·충격은 한 번의 WebGL 배치로 그립니다.

[실제 실행 영상 — 기본 강도, 비 멈춤, 강한 비와 일시정지](docs/screenshots/rain-motion.webm)

빗소리는 실내에서 듣는 부드러운 배경 빗소리와 불규칙한 물방울 타격음을 겹쳐 합성합니다. 날카로운 고주파와 전체 재생 크기를 줄이고, 좌우에 서로 다른 질감을 사용합니다. 24초 루프의 연결부를 섞어 반복 경계를 완화합니다. AudioContext와 반복 소스는 재사용하므로 켜기·끄기를 반복해도 소리가 중첩되지 않습니다.

### 성능과 접근성

- 비활성 탭에서는 렌더와 소리를 중단하고, 복귀할 때 지난 시간을 건너뛰어 계산합니다.
- `prefers-reduced-motion` 설정에서는 정지 화면으로 시작하며, 직접 재생할 수 있습니다.
- Canvas·WebGL 초기화 실패 또는 context 상실 시 정적인 CSS 야경으로 전환합니다. 소리 재생 실패는 시각 감상에 영향을 주지 않습니다.
- 컨트롤에 접근성 이름과 키보드 포커스 표시를 제공하며, 모바일 터치 영역을 확보합니다.

| 렌더 예산          | 가로 640px 이하 | 그 외 |
| ------------------ | --------------- | ----- |
| 최대 DPR           | 1.5             | 2     |
| Canvas당 최대 픽셀 | 100만           | 210만 |
| 최대 주 물방울     | 240개           | 560개 |
| 최대 창밖 빗줄기 | 420개 | 900개 |
| 최대 잔여 물막 조각 | 2,200개         | 5,000개 |
| 프레임 상한        | 30fps           | 60fps |

모든 기기에서 상한 fps를 보장하지는 않습니다.

도시 합성과 굴절용 배경 갱신은 모바일 최대 15fps, 데스크톱 최대 20fps로 별도 제한합니다. 사진의 점등·소등 버전과 구름 질감은 캐시하며 차량은 최대 40대, 개별 창문 변화는 최대 1,800개 영역으로 제한합니다.

동시 충격은 최대 32개, 충격당 미세 튀김은 최대 4개입니다. 전체 GPU 배치는 최대 5,800개로 제한합니다.

## 검증

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

브라우저 테스트는 Playwright Chromium을 사용합니다. 아래 서버를 켜 둔 상태에서 별도 터미널로 테스트를 실행하세요.

```sh
# 최초 1회 브라우저 설치
npx playwright install chromium

# 터미널 1: 테스트 기본 주소에서 실행
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

```sh
# 터미널 2
npm run test:e2e
```

다른 서버를 검사하려면 `QA_BASE_URL` 환경 변수를 지정합니다. 단위 테스트 46개를 통과했습니다. 직전 전체 브라우저 검사 26개 통과 후, 차량 가시성·교통량 변경과 관련된 5개 검사를 통과했습니다. 검사 범위와 실행 환경은 [검증 기록](docs/verification.md)에 정리했습니다.

## 자산과 알려진 한계

배경은 mos design이 촬영한 실제 도쿄 에비스의 고층 야경 사진이며 Unsplash License로 사용합니다. 사진은 프로젝트에 포함해 같은 출처에서 제공하며, 방문 시 외부 사진 서버에 요청하지 않습니다. [사진 원문](https://unsplash.com/photos/a-view-of-a-city-at-night-from-the-top-of-a-building-7d7FpQJEgIA) · [라이선스](https://unsplash.com/license) · [자산 상세와 이전 사진 출처](public/images/ATTRIBUTION.md). 물방울·대체 화면·SVG 아이콘은 코드로 생성하고 빗소리는 브라우저에서 합성합니다. 배경음악 **Rain — oh**는 이 프로젝트용으로 새로 구성·합성했습니다. 외부 음원·샘플·웹 폰트는 사용하지 않습니다. [음악 제작 출처](public/audio/ATTRIBUTION.md) · [MP3](public/audio/oh-rain.mp3). 글꼴은 기기에 설치된 Arial, Malgun Gothic, Georgia와 시스템 대체 글꼴을 사용합니다. 개발 도구와 배포 헬퍼의 라이선스는 [서드파티 고지](THIRD_PARTY_NOTICES.md)에 기록했습니다.

- 실제 빗물을 촬영한 영상이 아니라, 실제 도시 사진 위에 실시간으로 생성하는 효과입니다. 곡면 굴절·표면 부착·경로상의 작은 방울 흡수는 근사 표현이며 정확한 광학·충돌·유체 시뮬레이션은 아닙니다.
- 창밖 비·빗안개·구름·차량 불빛은 합성 애니메이션이며 실제 교통·날씨 정보가 아닙니다. 건물별 비의 가림·조명 산란은 물리적으로 계산하지 않습니다. 사무실 소등은 사진의 밝은 픽셀과 도로·하늘의 근사 구분을 사용하므로 건물별 실제 조명 상태와 일치하지 않습니다. 기기 시간·시간대가 잘못 설정되면 조명 일정도 그 설정을 따릅니다.
- 차량은 백색 헤드라이트·붉은 후미등과 약한 젖은 노면 반사를 사용합니다. 강우·거리별 지수 감쇠와 광량을 보정한 부드러운 번짐을 적용해, 비가 강할수록 더 흐리고 어두워집니다. 거리 450~1,650m와 강우 계수는 사진에 맞춘 가정이며 실측 광학·강수량 시뮬레이션이 아닙니다. [감쇠 원리](https://pbr-book.org/4ed/Volume_Scattering/Transmittance).
- 배경은 약 20층 높이의 창가 분위기를 목표로 선택했으나 실제 촬영 층수는 출처에 없으며, 시각상 더 높게 보일 수 있습니다.
- 음악은 `scripts/compose-rain.py`에 악보·음색 합성·믹스를 보존했습니다. 재생에는 Python이 필요 없으며, 재생성을 원할 때만 `python -m pip install numpy scipy imageio-ffmpeg` 후 `python scripts/compose-rain.py`를 실행합니다. MP3는 첫 재생 시 약 2.08MB를 내려받고, 32kHz 디코딩 버퍼는 약 26.6MB를 사용합니다(브라우저가 다른 샘플레이트를 사용하면 달라짐).
- 빗소리는 현장 녹음이 아닌 24초 합성 루프입니다. 재생 동작·파형·고주파 억제는 검사했으나 실제 스피커·이어폰별 청취 품질은 별도 확인이 필요합니다.
- 모바일은 뷰포트 에뮬레이션으로 검사했습니다. 실제 휴대전화·Safari·Firefox와 장시간 실기기 성능은 미검증입니다.
- 전체 화면과 소리 재생은 브라우저·운영체제 정책에 영향을 받습니다.
- 설정은 저장하지 않으며, 새로 접속하면 기본값으로 돌아옵니다.

## 배포와 저장소

현재 공개 사이트는 [Sites](https://rain-window.okorion.chatgpt.site)에 배포되어 있습니다. `npm run build`가 생성하는 `dist/`를 루트 경로로 서비스하는 정적 호스팅에도 배포할 수 있습니다. 별도 서버·로그인·DB·AI API·날씨 API·위치 권한은 사용하지 않습니다.

이 GitHub 저장소는 공개 소스 저장소입니다. Sites 배포용 저장소와는 **수동으로 동기화**하며, GitHub push가 자동 동기화나 사이트 재배포를 실행하지 않습니다. `.openai/hosting.json`은 현재 Sites 프로젝트에 연결된 설정이므로, 포크를 별도 Sites 프로젝트로 배포할 때는 자신의 프로젝트 설정을 사용하세요.
