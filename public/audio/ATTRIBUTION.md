# Rain — oh

- 곡명: Rain / 아티스트 표시: oh (사용자가 지정한 표기)
- 제작일: 2026-09-22. Rain Window를 위해 코드로 새로 구성한 악보와 합성 음원.
- 74 BPM, 4/4, Db major·Bb minor 계열, 32마디, 약 1분 44초.
- 전자피아노·짧은 건반 멜로디·베이스·킥·브러시 스네어·하이햇, 스테레오 잔향.
- 전반적인 감성 로파이 분위기를 참고하되 Lee의 Rain 음원·샘플·멜로디·채보 데이터를 사용하지 않음. 기존 곡의 공식 편곡·커버·협업이 아닌 독립적으로 구성한 프로젝트 음원.
- 일반적인 재즈 화성 Dbmaj9–Bbm9–Ebm9–Ab13 등을 새 보이싱·멜로디·리듬으로 구성. 실제 악기 녹음이 아닌 결정적 난수 시드 기반 합성.
- 재생 파일: `oh-rain.mp3`, 32 kHz stereo, 160 kbps, 약 2.08 MB. 처음 사용자가 켤 때 같은 사이트에서 로드.
- 생성 원본: 저장소의 `scripts/compose-rain.py`, 구조·수치: `score.json`. 외부 샘플이나 유료 음원 라이브러리가 필요하지 않음.
- 제작 도구: Python, NumPy, SciPy, imageio-ffmpeg/FFmpeg(libmp3lame). 제작 도구 실행 파일은 웹 배포에 포함하지 않음.
